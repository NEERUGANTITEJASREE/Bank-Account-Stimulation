# Bank-Account-Stimulation
# 🏦 Java Bank Account Simulation

## 📌 Description

A console-based banking system built using Java OOP concepts. It simulates real-world bank operations like deposit, withdrawal, and transaction tracking.

## 🎯 Features

💰 Deposit money
💸 Withdraw money
📊 Check balance
📜 Transaction history
🔁 Menu-driven system

## 🛠️ Technologies Used

Java (JDK)
ArrayList (for transactions)
VS Code / IntelliJ

## ▶️ How to Run

```bash
javac BankApp.java
java BankApp
```
